## Requests and release checklist

1. Identify the original code copyright holder(s), repository owner and institutional ownership policy.
2. Request written permission for the specific source files, modifications, public distribution, proposed repository, and license; attach the manifest at `PUBLIC_RELEASE_MANIFEST.md`.
3. Ask each contributor to complete the ownership and contribution confirmations in `AUTHOR_DECLARATIONS.md`.
4. Record third-party code provenance and license notices; replace or remove copied code only with rights-holder approval and a documented clean-room process.
5. Do not add a root open-source license until authorized owners approve exact license and scope.
6. Create a fresh data-free archive from an approved allow-list; scan every archive member for secrets, records, model bundles, local paths, and restricted content; test that exact archive.
7. Obtain project-owner written approval before public upload.

Written upstream permission request template: `UPSTREAM_CODE_PERMISSION_REQUEST.md`. Redistribution checklist: `PUBLIC_RELEASE_MANIFEST.md`.

The inventory is path-based and does not replace line-level copied-code review, ownership declarations, or third-party license scanning.
