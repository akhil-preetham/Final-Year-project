# CARDIODIAG dataset compatibility matrix

**Updated:** 2026-11-07. Dataset sizes are source-record counts, not necessarily unique patient counts. “Missingness” refers to published source documentation; feature-specific local counts should be computed from the exact downloaded version before analysis. A compatibility verdict is tied to CARDIODIAG’s existing tabular angiographic CAD model and source target (`>50%` stenosis), not a general statement of dataset value.

## Candidate datasets

| Dataset | Endpoint / cohort / size | Inputs, units, missingness | Lineage / overlap evidence | Fit to current pipeline and appropriate role |
|---|---|---|---|---|
| UCI Heart Disease | Binary presence (`num=1..4`) vs absence (`num=0`); source docs define presence by >50% diameter narrowing in a major vessel. Four historical cohorts: Cleveland 303, Hungary 294, Switzerland 123, VA Long Beach 200; 920 records total. | 13 shared clinical/categorical variables: age (years), sex, chest-pain code, resting BP (mmHg), cholesterol (mg/dL), FBS >120 mg/dL, resting ECG code, max HR (bpm), exercise angina, oldpeak, slope, major-vessel count, thal code. `?`/other missing markers occur; local source audit found zeros in cholesterol and BP requiring explicit sensitivity rules. | Already directly in CARDIODIAG external pilot and its components are represented in Heart5. | Pipeline-compatible for retrospective internal/LOSO benchmarking, but not independent validation. Component-wise split must prevent Heart5 leakage; no new external claim. |
| Statlog Heart | Binary class 1/2; related heart-disease task. 270 records, often described as Hungarian Institute of Cardiology data. | 13 mixed categorical/real predictors; units follow UCI Cleveland-style definitions: age years, resting BP mmHg, cholesterol mg/dL, max heart rate bpm, binary/ordinal clinical fields. UCI: no missing values. | Local row-level audit found 270/270 exact matches to Cleveland after target harmonization. UCI itself says similar to the Heart Disease database. | Exclude as independent test; usable only as alias/duplicate-data reproducibility check. |
| Z-Alizadeh Sani | CAD vs Normal by Cath; UCI defines CAD as stenosis >=50%. 303 patients from Shahid Rajaei Center, Tehran; 216 CAD / 87 Normal in local workbook. | 54 described features grouped demographics, symptoms/exam, ECG, lab/echo; local workbook has 55 predictor columns (discrepancy recorded). Age years; FBS mg/dL; many numeric/categorical/binary attributes; local file has no missing cells. | Already used in `CD-XD-003`. Different hospital stated; no identifiers to rule out person overlap. | Existing three-field mapping can run, but endpoint differs exactly at 50%; source result is a transport stress test, not confirmatory exact-endpoint validation. Additional features lack a proven semantic map. |
| UCI Heart Failure Clinical Records | Death event during follow-up among patients with existing HF; 299 records, 12 predictors plus target. | Age (years), anaemia, CPK (mcg/L), diabetes, ejection fraction (%), hypertension, platelets (kiloplatelets/mL), serum creatinine (mg/dL), serum sodium (mEq/L), sex, smoking, follow-up time (days); no missing values per UCI. Follow-up `time` is excluded from predictors. | Acquired 2026-11-07 and registered in `data/manifests/uci_heart_failure_519.json`; no patient-level linkage performed. | Separate exploratory death-event classification task; no common horizon, not time-to-event analysis, not CAD validation. |
| UCI Myocardial Infarction Complications | 12 possible MI complications from admission through day 3; 1,700 instances, 111 input fields / 12 output fields. | Clinical history, exam, ECG and laboratory variables, mixed ordinal/categorical/boolean/real. Many fields have missing values. UCI's admission-time input excludes columns 93–95 and 100–105; this analysis also excludes all output fields and two contemporaneous outcome proxies. | Acquired 2026-11-07 and registered in `data/manifests/uci_mi_complications_579.json`; UCI says record ID cannot be related to participant. | Separate exploratory classification of any recorded lethal outcome; not CAD diagnosis or validation. |
| PTB-XL v1.0.3 | Multi-label ECG diagnostic, rhythm, and morphology statements; PhysioNet v1.0.3 page reports 21,799 10-second ECGs from 18,869 patients. Collection at PTB, Germany, 1989–1996. | 12-lead waveforms; WFDB 16-bit, resolution 1 µV/LSB, with 500 Hz and downsampled 100 Hz variants. Patient and record metadata plus SCP-ECG labels. Archive page does not publish a complete fieldwise missingness table; inspect frozen metadata and labels before analysis. This is not a tabular CAD stenosis endpoint. | No local files or manifest show it has been used. PTB-XL+ explicitly derives/supplements PTB-XL; no independence from derived PTB-XL material. | Not compatible with tabular CAD pipeline. Strong candidate for a separate ECG interpretation task or ECG-specific domain-shift demonstration. Do not use ECG diagnosis labels as angiographic CAD. |
| PTB-XL+ v1.0.1 | ECG-derived features, median beats/fiducials and algorithm interpretation statements tied to PTB-XL ECG records; same upstream patient cohort. | Structured ECG signal features from two commercial and one open-source algorithm; features have algorithm-dependent units/definitions and include waveform-derived values. Need inspect official codebooks and quantify feature missingness before task design. | Official PhysioNet says derived from PTB-XL; direct patient overlap is by design. | Useful only as a feature-engineering benchmark paired with PTB-XL for ECG labels. Never an independent external validation cohort. Use caution with commercial algorithm output provenance and target leakage. |
| Chapman-Shaoxing-Ningbo ECG (PhysioNet “A large scale 12-lead electrocardiogram database for arrhythmia study”) | ECG rhythm/arrhythmia and additional cardiac condition labels; official PhysioNet describes 45,152 patients in the combined database. The original Chapman-Shaoxing subset has 10,646 patient ECGs; Challenge 2021 version has 10,247 Chapman-Shaoxing recordings. Do not conflate these with each other or the Ningbo subset. | 12-lead resting ECG, 10 seconds, 500 Hz; amplitude in microvolts. Diagnoses stored separately. Official page does not provide a complete fieldwise/record-level missingness table; profile exact frozen release before analysis. No tabular stenosis predictors. | No local CARDIODIAG use found. Another dataset than PTB-XL; no overlap evidence with CARDIODIAG cohorts. Challenge bundles may include PTB-XL and other cohorts—exclude those portions or trace IDs before calling the bundle independent. | Separate ECG arrhythmia classification/domain-shift task; not compatible with current tabular CAD model. |
| EPHNOGRAM v1.0.0 | 69 synchronized ECG/PCG records from 24 healthy adults age 23–29, acquired during rest, walking, running, biking; 8 records are 30 seconds and 61 are 30 minutes. Not a cardiovascular-disease outcome dataset. | Three-lead ECG plus single PCG stethoscope, auxiliary PCG/audio in some records; WFDB/MAT formats. Units/sample frequencies are signal-header-defined and must be read from headers; poor quality records intentionally included and flagged in spreadsheet. No clinical disease labels. | No local use found; non-patient healthy volunteer dataset. | Not external validation or CAD benchmark. Suitable only for signal-processing, quality detection, or stress-condition representation experiments in a separate task. |

## Compatibility rule

No ECG signal, ECG diagnosis, mortality, MI complication, or HF survival endpoint should be merged into the current tabular angiographic CAD target. A separate task requires a separate frozen outcome, predictor-time definition, split unit (patient), evaluation protocol, and license/access record. Candidate acquisition does not itself validate any CARDIODIAG claim.
