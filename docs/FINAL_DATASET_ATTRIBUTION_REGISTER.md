# Final CARDIODIAG dataset attribution register

**Updated:** 2026-11-07. This is the consolidated source of truth for dataset identity, DOI/version, license/access, attribution and release disposition. “Used” means present in an implemented experiment or model-development/replication stage. “Screened” means source data were inspected for provenance/compatibility but not used to establish a new performance claim. A public record is not treated as permission beyond its published license.

## Attribution notices and project citation policy

Dataset-specific notices for locally acquired, openly licensed releases are under [`data/attribution/`](../data/attribution/README.md). The notice includes source, citation, DOI, license, and material project caveats. These notices are not a blanket permission for a multi-dataset derived composite. Cite the exact version actually analyzed; retain source notices, license links and modification statements. For PhysioNet releases, use the version-specific record and the dataset paper requested on the record. For EPHNOGRAM, preserve ODC-By as ODC-By; do not relabel it CC BY.
