# Final manuscript dataset, overlap and availability section

This section is the canonical dataset wording for the manuscript. It is based on the 2026-11-06 source audit and should replace older dataset-provenance paragraphs when compiling the paper.

## Datasets and provenance

The historical development and replication benchmarks were the 918-row Five States file (`heart5.csv`) and the 1,000-row Mendeley Cardiovascular Disease Dataset (version 1; DOI `10.17632/dzz48mvjht.1`). The local Five States file is a derived composite: all 918 records map to observed UCI Heart Disease component fields and labels (914 unique source-row matches and four ambiguous matches due to source missingness). The exact 1,190-row upstream Kaggle artifact, its version/license and the full transformation/imputation history were not recovered. The Five States file therefore has unresolved standalone licensing and is not an independent cohort relative to its UCI components. The Mendeley record declares CC BY 4.0, but its codebook defines only presence/absence; the diagnostic reference standard, stenosis threshold and predictor index time are not stated. It is used only as historical replication evidence, not pooled with the angiographic endpoint.

The four UCI Heart Disease cohorts (Cleveland, Hungary, Switzerland and VA Long Beach; 920 records total; DOI `10.24432/C52P4X`) supplied the retrospective CD-XD-002 leave-one-source-out pilot. These records overlap the Heart5 composite. The separately downloaded UCI Statlog (Heart) dataset (270 records; DOI `10.24432/C57303`) adds no new records for this analysis: all 270 rows exactly match Cleveland after label harmonization. Neither source is described as independent external validation.

The UCI Z-Alizadeh Sani dataset (303 patients; DOI `10.24432/C5Q31T`) was used in CD-XD-003 as a transport stress test. Its reported Tehran hospital differs from the UCI development sources, but the public workbook lacks patient IDs for cross-source linkage. Its CAD label uses `>=50%` stenosis while the UCI source uses `>50%`. The cohort was already examined and is not an untouched confirmatory set.

The AngioCAD dataset (Zenodo DOI `10.5281/zenodo.15826856`, CC BY 4.0) reports 413 labelled IDs from a separately reported Isfahan hospital. The released workbooks contain matching clinical features for 377 IDs; 36 labels lack a matching feature row. Its positive bin starts at 51%, but the negative 26–50 bin prevents isolation of exact-50% cases. The workbook does not specify age/FBS units; historical age-as-years and FBS-as-mg/dL mappings are assumptions, and the age/FBS-excluded analysis is post hoc. AngioCAD supports a one-site source-separated cohort evaluation, but common person identifiers are unavailable, so cross-dataset patient independence is unverified. The target had already been inspected; this is not a pristine final holdout.

Duke ACATH (3,504 patients; Vanderbilt Biostatistics distribution from the Duke Cardiovascular Disease Databank) was evaluated in CD-XD-005 as an exploratory transport stress test. The source permits use with attribution but provides no dataset DOI or clear standardized redistribution license. Its `>=75%` stenosis outcome differs from the UCI `>50%` outcome, and cholesterol is missing for 1,246 records. The reported institution is distinct; participant-level de-duplication was not possible, and no independence claim is made.

The 2026 Mendeley Heart Disease Clinical release (v1, DOI `10.17632/nt4y898vyh.1`, CC BY 4.0) was used only for provenance screening. Its 918 labelled rows exactly match Heart5 as a multiset; it is a duplicate release, not an additional cohort. The 70,000-row Kaggle Cardiovascular Disease dataset is a separate examination-time classification benchmark with a different feature schema and target. Kaggle lists its license as `Unknown`; the data and derived results are not cleared for redistribution, and its use rights remain unresolved. It is not used as external validation of the angiographic CAD model.

No ECG waveform, heart-failure mortality, or post-MI complication dataset was acquired or merged into this tabular CAD task. UCI Heart Failure, UCI MI Complications, PTB-XL, PTB-XL+, Chapman-Shaoxing-Ningbo and EPHNOGRAM are separate research tasks; their outcome definitions or modalities do not match the CARDIODIAG endpoint.

## Data availability

Dataset identity, source URLs, DOI/version, hashes, access and license findings are recorded in the final attribution register and the machine-readable manifests. No restricted dataset is included in the proposed code release. The 1,000-row Mendeley, UCI Heart Disease, Statlog, Z-Alizadeh Sani, Mendeley 2026 and AngioCAD source records carry CC BY 4.0 and have individual attribution notices; raw data are omitted from the proposed data-free release. EPHNOGRAM, if later acquired, must retain its distinct ODC-By terms. The Heart5/Five States composite and Kaggle 70K dataset are excluded because exact upstream records or rights are unresolved. Duke raw files and row-level derivatives are excluded pending explicit redistribution clarification. MultiD4CAD was not acquired and is restricted under its DUA.

## Code availability

The source repository contains code, tests, dependency lock, and data adapters, but no public package has been generated or authorized. The root project has no code license file, so source redistribution authority must be confirmed before release. Existing `dist/*.zip` snapshots are legacy artifacts, retained unchanged, and are not release-approved because they include source data and/or 70K-derived outputs whose rights are unresolved. The proposed allow-list and exclusions are in `FINAL_DATA_RELEASE_MANIFEST.md`.
