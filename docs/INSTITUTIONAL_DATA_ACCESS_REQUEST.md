# Institutional cohort access request template

**To:** Principal investigator / data custodian / research data access office

**Subject:** Request for feasibility and access determination for an independent-site evaluation of a frozen CAD prediction model

Dear [name/office],

We request a feasibility discussion and the applicable access pathway for a retrospective, independent-site evaluation of a research-only coronary artery disease prediction model. This is not a request to transfer identifiable records by email or to bypass institutional review.

The proposed evaluation will score a frozen model once using prespecified clinical predictors recorded before angiography and an agreed angiographic endpoint. The current model was developed using historical public cohorts. It has not demonstrated reliable unseen-site generalization. We seek an independent cohort and will not use its labels for model selection, feature selection, calibration, or threshold tuning.

Please advise whether your institution can support a study with:

- a patient-level cohort and recruitment period/site description;
- an independently defined >50% major-coronary stenosis endpoint or a documented alternative suitable for a separately named task;
- predictor names, units, timing and missingness; endpoint ascertainment and adjudication process;
- a lawful, secure analysis route with no unauthorized transfer of patient-level data;
- overlap/independence assessment relative to source cohorts; and
- the required ethics, data-use agreement, security review and authorship/collaboration policies.

We will provide a frozen protocol, model/software hashes, data dictionary, analysis plan, intended data flow, and publication plan for review before any outcome labels are accessed. Aggregate outputs will be subject to your disclosure review. Access and collaboration are not presumed.

Project lead/contact: [name, institutional email]  Institution: [name]  Date: [date]

Please indicate: available cohort / not available / referral pathway; required approvals; likely timeline; and any terms governing access, derived outputs, authorship, and publication.
