# Documentation consolidation

The repository contains 148 Markdown files, including detailed research
documents, package documentation, reports, manuscript notes, and copies inside
distribution trees.

## Primary-document proposal

Use the following as the navigation and maintenance entry points:

- `README.md`
- `docs/architecture/ARCHITECTURE.md`
- `docs/methodology/METHODOLOGY.md`
- `docs/research/RESEARCH_STATUS.md`
- `docs/research/DATASETS.md`
- `docs/research/MODEL_REGISTRY.md`
- `docs/research/REPRODUCIBILITY.md`
- `docs/reports/FINAL_RESEARCH_REPORT.md`
- `docs/maintenance/SESSION_HANDOFF.md`

The proposed documents should link to, rather than replace, detailed literature
reviews, audit reports, mathematical designs, and evidence ledgers.

## Findings

There are overlapping provenance, reproducibility, final-status, audit, and
handoff documents. The distribution trees also contain copied documentation.
These copies are release snapshots and should not be edited as if they were
the source documentation.

## Action

Do not delete or merge scientific documents during the first cleanup pass.
Create a navigation index and mark canonical documents before moving content.
The existing README already documents the active architecture and commands,
but several command paths and historical copies should be checked as part of
the final verification.
